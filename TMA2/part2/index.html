♡ Web Learning App ♡

Welcome to the Online Learning Management System, where both learners and educators can access a small-scale interactive learning system for online courses.

For Teachers and Admins:

  1. Create and Manage Units: As a subject matter expert, you have the ability to create, update, and delete learning units to customize the curriculum.

  2. Uploading Lessons and Quizzes

    How to upload course content and quizzes using the custom XML format:

    • Lessons must be saved in XML format (fil extension .xml). You can use the Notepad app to save the file with a .xml extension.
    • Each lesson must include at least one question with three answer choices, where only one answer is correct.
    • (Optional) You can attach a media file that will be displayed at the end of each lesson.
    Lesson and Quiz Format
    
<unit>  <---- You can use any title you like here (unit, lesson, course) 
    <title>Your Lesson Title</title>
    <content>  <---- Indicate the start of the container tag, which will hold all your learning content 
        <header>Headers can be used throughout lesson and will be transformed to a header title</header>
        <text>Lesson content wrapped within text here wll be transformed into a paragraph </text>

        <list>  <---- Indicate the start of a list. All items within this will become bullet points
            <item>Bullet Point 1</item>
            <item>Bullet Point 2</item>
        </list> 

        <text>You can have as many as < header >, < text >, < list > and < item > tags within content as you like </text>
    </content>
                        
    <questions>  <---- Start of the questions container
        <question>  <---- Indicates the start of a new question 
            <text>Text of first quiz question here</text>
            <answers>  <---- Indicates the start of the question's answer options 
                <answer correct="false">List off 3 possible answers</answer> 
                <answer correct="false">Mark an incorrect answer by setting the value to false</answer>
                <answer correct="true">Mark the correct answer by setting the value to true</answer>
            </answers>
        </question>  <---- End of this specific question 
        
        ... More questions may be entered in here if desired

     </questions> <---- End of all the lesson's questions
</unit> <---- End of the entire unit/lesson/content
    HTML Special Character Codes

    Some characters cannot be used directly in HTML content and must be replaced with:

    • &lt; = < (Less-than sign)
    • &gt; = > (Greater-than sign)
    • &amp; = & (Ampersand)

    Can see more here: https://www.w3schools.com/html/html_entities.asp
    Important Notes
    • All tags (<tags>) must have corresponding closing tags.
    • Each lesson must include at least one question.
    • Each question must have exactly three answer choices.
    • Only one answer should be marked correct using correct="true".
    • Valid formats for optional media files are: JPEG/JPG, PNG, MP3, MP4

  3. Example Lesson:

    
<unit>
    <title>Introduction to Web Tech</title>
    <content>
        <header>Welcome to the Web Tech Tutorial!</header>
        <text>In this tutorial, you will learn about HTML, CSS, JavaScript, &amp; XML.</text>
        <header>This is a code sample:</header>
        
        <text>document.getElementById('id');</text>

        <text>You may be wondering, what language is this synatx in?</text>
        <list>
            <item>HTML?</item>
            <item>CSS?</item>
        </list>
        <text>The answer is: Javascript!</text>
    </content>
    <questions>
        <question>
            <text>What will you learn in this Web App?</text>
            <answers>
                <answer correct="true">Create a web page that shows a person's favorite foods.</answer>
                <answer correct="false">Use Java, C++, and Python to build websites.</answer>
                <answer correct="false">Write C++ programs for web applications.</answer>
            </answers>
        </question>
    </questions>
</unit>

    The inner of the content will show up as:

    Welcome to the Web Tech Tutorial!

    In this tutorial, you will learn about HTML, CSS, JavaScript & XML.

    This is a code sample:

    document.getElementById('id');

    You may be wondering, what language is this syntax in?

    • HTML?
    • CSS?

    The answer is: Javascript!
