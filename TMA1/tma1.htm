Part 2

A web application that can help people to learn the technologies covered in Unit 1, Unit 2, and Unit 3 of the course (HTML5, CSS3, JavaScript, XML, and Ajax). All related files are inside of: ...\TMA1\part2\

It has the following components:

  • A web-based system called 'Web Learning' with a banner, navigation menus, and buttons. It begins with a welcome page to greet the users, explaining what the application does, what they get from it, and how they should proceed.
  • The application has three pages of tutorials, accessible through navigation menus and buttons, to teach the technologies covered in Unit 1, Unit 2, and Unit 3.
  • The HTML5 tutorial teaches 5 page-structure elements and 6 new input types.
  • There is a quiz for each tutorial, accessible right after the tutorial page, as well as through the navigation menus and buttons.
  • After the submission button is hit, the quiz system grades the answers the learner has provided and shows the correct answers as well as the score in percentage.
  • The quiz system is designed so that questions can be easily edited, added, or deleted, and new quizzes can be easily created by editing/copying/pasting the associated unit's XML file (unit1Quiz.xml, unit2Quiz.xml, unit3Quiz.xml).
  • Uses the web technologies covered in Unit 1, Unit 2, and Unit 3 (HTML5, CSS3, JavaScript, XML, and Ajax).
  • Uses an external style sheet for all pages of the system to retain a consistent and user-friendly interface (...\TMA1\shared\styles2.css).
  • Does not use HTML5 tables to lay out the web page.

Algorithm Explanation:

  • When a link is clicked, an AJAX function is triggered.
  • This function chooses the appropriate HTML file to load, then uses AJAX to load it dynamically.
  • After loading, it initializes the required variables and attaches action listeners to the new elements.
  • These listeners then execute predefined functions: convertMeasurements(), calculateMortgage(), convertTime()
  • Rates and timezones are also predefined:
    • weightConversionRates, lengthConversionRates, areaConversionRates, volumeConversionRates, timeZones
  • When switching between sections, the HTML elements are removed from the DOM and then re-added via AJAX.
  • Since the JavaScript event listeners are attached to the specific instances of DOM elements, listeners attached to removed elements will not apply to the new elements.
  • So there is no need to destroy the action listeners or variables.
