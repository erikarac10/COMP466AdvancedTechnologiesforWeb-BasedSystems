Learn how to create and style web pages

HTML (HyperText Markup Language)

HTML is the standard markup language for creating web pages. It tells the web browser how to structure a web page.
This is done using elements like headings, paragraphs, links, and images.

Page Structure Elements:

  • <html> - Tells the Web Browser that the file is an HTML document.
  • <head> - Contains metadata about the HTML document, including links to stylesheets (CSS Covered below).
  • <header> - Represents introduction content or navigational links.
  • <body> - What the content of the HTML will have, such as text and images.
  • <main> - Represents the body content of the of the web page.
  • <section> - Defines a section, used to group related content together.
  • <h1> - Represents a header, used as titles of sections. <h1> is the highest level heading (h1-h6).
  • <p> - Defines a paragraph of text.
  • <button> - Creates a button that can be clicked to trigger an action.
  • <div> - Creates a section that will be styled with CSS.
  • <footer> - Represents the footer for the page.

Tags may also have a specific ID, so we can target them specifically.

New Input Types:

HTML5 also features different types of input the user can make on the page.

  • <input type="email"> - Takes an email address, the browser will validate the format of your input.
  • <input type="tel"> - Takes a telephone number.
  • <input type="url"> - Takes a URL. The browser will validate the format of your URL input.
  • <input type="number"> - Takes numeric values, with set minimum and maximum values.
  • <input type="range"> - Makes a slider for values within a range.
  • <input type="date">- Makes a date picker for selecting dates and converts the input into a date format.

CSS (Cascading Style Sheets)

CSS is used to style and layout web pages. You can change the color, font, size, spacing, and layouts using CSS.

Basic CSS Styling:

  • Display: display: flex;
    - Defines a flex container to enable flexible layout for its child elements.
  • Flex-Direction: flex-direction: column;
    - Specifies the direction of the flexible items inside a flex container in column direction
  • Align-Items: align-items: center;
    - Aligns flex items along the cross axis of the flex container with center alignment.
  • Background Color: background-color: #ddbfbf;
    - Sets the background color to the hexadecimal color code #ddbfbf.
  • Text Color: color: white;
    - Sets the color of the text content to white.

You can also apply styles to only specific elements you've defined with IDs (id="greetings").

Example CSS:


body {
    display: flex;
    flex-direction: column;
    align-items: center;
    background-color: #ddbfbf;
}

#greetings {
    background-color: #c48484;
}

#message {
    font-size: 20px;
    color: #fff;
}

AJAX Basics

Asynchronous JavaScript and XML (AJAX) allows you to upload things to a web page. It involves making XMLHttpRequests to fetch data from a server and handling the response it gave.


//AJAX request
var xhr = new XMLHttpRequest(); //Variable for the new XMLHttpRequest
xhr.onreadystatechange = function() { //When it is ready, define the function that it will run once it is ready
    if (this.readyState == 4 && this.status == 200) {
        document.getElementById("ajaxResponse").innerHTML = this.responseText;
    }
};

xhr.open("GET", 'xmlFile.xml', true); //Send 'GET' request to the file "xmlFile.xml"
xhr.send(); //Send the request/execute it

Example Javascript:


//Event handling
document.getElementById("buttonID").addEventListener("click", function() {
    alert("The button named 'buttonID' was clicked!");
    loadXMLFunction();
});

function loadXMLFunction() {
    console.log("Loading XML...");

    //Create an XMLHttpRequest to load XML and XSL files
    var xmlRequest = new XMLHttpRequest();
    var xsltRequest = new XMLHttpRequest();

    //Load the XML file
    xmlRequest.open("GET", "xmlFile.xml", true);
    xmlRequest.onreadystatechange = function() {
        if (xmlRequest.readyState === 4 && xmlRequest.status === 200) {
            //Load the XSL file once the XML is loaded
            xsltRequest.open("GET", "xsltFile.xslt", true);
            xsltRequest.onreadystatechange = function() {
                if (xsltRequest.readyState === 4 && xsltRequest.status === 200) {
                    //Transform XML using XSLT
                    transformXML(xmlRequest.responseXML, xsltRequest.responseXML);
                }
            };
            xsltRequest.send();
        }
    };
    xmlRequest.send();
}

function transformXML(xml, xslt) {
    
    if (window.XSLTProcessor) { //Check for browser compatibility
        var processor = new XSLTProcessor();
        processor.importStylesheet(xslt);

        var resultDocument = processor.transformToFragment(xml, document); //Perform the transformation

        //Insert the transformed result into the food section
        document.getElementById("foodsSection").innerHTML = '';
        document.getElementById("foodsSection").appendChild(resultDocument);
    }
}

Learn about XML and how it is used in web development

XML (eXtensible Markup Language)

XML is a markup language that defines rules for encoding documents in human-readable and machine-readable form. It is used to store and transport data. An XML document has nested elements, similar to HTML, but you can create your own tags.

Example XML:


<?xml version="1.0" encoding="UTF-8"?> <!-- XML declaration -->

<person> <!-- person element -->
    <name>My Name!</name> <!-- your name here -->
    <age>45</age> <!-- your age -->
    <favoriteFoods> <!-- section for your favorite foods -->
        <food>Pizza</food> <!-- first favorite food -->
        <food>Sushi</food> <!-- second favorite food -->
    </favoriteFoods>
</person>

XML Schema (XSD)

XML Schema Definition (XSD) is used to define the structure, content, and data types in the created tags of your of XML documents.

An XSD as a set of rules that your XML document must follow. It verifies that the XML file contains the right types of data, the correct hierarchy of elements and other structural constraints.

<xs:element>: Defines a XML element's name and type.

<xs:complexType>: Describes an element with nested child elements.

<xs:sequence>: Defines the order and occurrences of child elements within the complex type.

Example XSD:


<?xml version="1.0" encoding="UTF-8"?>
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">

    <!-- Define the root element 'person' for general people -->
    <xs:element name="person">
        <xs:complexType>
            <xs:sequence>
                <xs:element name="name" type="xs:string"/> <!-- A person's name -->
                <xs:element name="age" type="xs:integer"/> <!-- A person's age -->
                <xs:element name="favoriteFoods">
                    <xs:complexType>
                        <xs:sequence> <!-- Unbounded list of fav foods -->
                            <xs:element name="food" type="xs:string" maxOccurs="unbounded"/> 
                        </xs:sequence>
                    </xs:complexType>
                </xs:element>
            </xs:sequence>
        </xs:complexType>
    </xs:element>

</xs:schema>

XSLT (XML Stylesheet Language Transformations)

XSLT is used to transform your XML document into HTML format, or other formats, such as CSS.

<xsl:stylesheet>: Root element defining the XSLT version and namespace.

<xsl:template>: Defines how XML content should be transformed - will matche your XML nodes and define the output.

<xsl:for-each>: Iterate over a set of XML nodes and apply the template to each one.

Example XSLT:


<?xml version="1.0" encoding="UTF-8"?> <!-- XML declaration -->

<xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">

    <!--Template to match the root element -->
    <xsl:template match="/person">
        <html>
            <head>
                <title>Person's Information</title>

                <style> <!-- Add some in-line CSS for display styling -->
                    body { font-family: Arial, sans-serif; margin: 20px; }
                    h1 { color: #333; }
                    p { margin: 5px 0; }
                </style>

            </head>
            <body>
                <h1>Person's Information</h1>
                <p><strong>Name: </strong> <xsl:value-of select="name"/></p>
                <p><strong>Age: </strong> <xsl:value-of select="age"/></p>
                <h2>Favorite Foods</h2>
                <ul>
                    <xsl:for-each select="favoriteFoods/food">
                        <li><xsl:value-of select="."/></li>
                    </xsl:for-each>
                </ul>
            </body>
        </html>
    </xsl:template>
</xsl:stylesheet>
