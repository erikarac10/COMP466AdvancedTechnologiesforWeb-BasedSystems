COMP 466 – Advanced Technologies for Web-Based Systems

Coursework completed for COMP 466 – Advanced Technologies for Web-Based Systems at Athabasca University as part of my Bachelor of Science, Major in Computing and Information Systems.

This repository contains three major assignments covering client-side web development, server-side programming, database-backed applications, ASP.NET/C#, web deployment, and full-stack application design.

TMA 1 – Client-Side Web Technologies

TMA 1 is a multi-part client-side web application demonstrating HTML, CSS, JavaScript, XML, XSLT, AJAX, and interactive browser functionality.

Projects include:
- An XML/XSLT-based resume using structured XML data and XSLT for browser presentation
- An interactive web technology learning system covering HTML5, CSS3, JavaScript, XML, and AJAX
- XML-driven quizzes with automated grading and percentage-based results
- An interactive JavaScript slideshow
- Weight conversion tools
- Length conversion tools
- Area conversion tools
- Volume conversion tools
- Mortgage calculations
- Canadian time-zone conversion
- Dynamic browser interaction using JavaScript and AJAX

The assignment integrates multiple applications through a shared interface and uses JavaScript and AJAX for dynamic client-side interaction.

TMA 2 – PHP/MySQL Web Applications

TMA 2 focuses on server-side development, authentication, relational databases, and dynamically generated web applications using PHP and MySQL.

Part 1 – Online Bookmark Manager

A database-backed bookmark management application featuring:

- User registration and authentication
- Individual user bookmark collections
- Adding, editing, and deleting bookmarks
- URL validation
- Database-backed CRUD operations
- Aggregation and display of popular bookmarks
- PHP and MySQL integration

A database-driven educational web application supporting:

- Learner registration and login
- Courses, units, lessons, quizzes, and multimedia content
- Lesson selection and continuation functionality
- Database-backed educational content
- A custom Educational Markup Language (EML)
- A PHP server-side parser for transforming EML content into browser-rendered HTML
- Lesson quizzes and assessment functionality
- Relational database design
- SQL database scripts
- Server-side application development
- Live web-server deployment

This assignment emphasized full-stack application architecture, database design, server-side processing, and dynamic content delivery.

TMA 3 – ASP.NET/C# Web Applications

TMA 3 focuses on server-side web development using ASP.NET and C#, application state, dynamic interfaces, and deployment of web applications to a live hosting environment.

Part 1 – Visitor Information Application

An ASP.NET/C# application that demonstrates server-side request processing and persistent state by:

- Visitor tracking
- Persistent cookies
- Client IP information
- Client time-zone information
- Server-side request processing

An interactive slideshow application featuring:

- A collection of images and captions
- Server-side image metadata
- Start and stop controls
- Sequential playback
- Randomized playback
- Previous and next navigation
- Dynamic slideshow controls

A progressively developed online computer store built with ASP.NET/C#.

Functionality includes:

- Product browsing and navigation
- Computer and component selection
- Custom computer configuration
- RAM selection
- Storage selection
- CPU selection
- Display selection
- Operating system selection
- Audio component selection
- Compatibility-aware customization
- Dynamic price calculations
- Shopping cart and order summaries
- Customer registration and authentication
- Account management
- Cookies and application state
- Server-side application logic
- Deployment to a live web server

The project involved analyzing existing e-commerce systems, designing the application architecture and user interface, implementing server-side functionality, and deploying the completed application.
